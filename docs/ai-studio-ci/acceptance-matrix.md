## Evidence boundary

The local focused evidence is limited to the named methods and prior accepted focused suite results. H2/MockMvc evidence is not represented as PostgreSQL evidence. The real HTTP evidence endpoint is test-profile-only, owner-scoped, and returns SQL stage/status/attempt counts plus fake-provider invocation counts without IDs, credentials, or request bodies. No GitHub run or production acceptance is claimed here.
